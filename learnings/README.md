# learnings/

The AI Learning Track corpus. Originally authored as a Confluence series for team-internal knowledge sharing on Claude Code adoption. Generic content (not company-specific); migrated here for public access.

## Planned contents

The corpus is a 12-page series covering:

- First-week orientation: what to do in your first week with Claude Code
- Insights: high-leverage lessons across the first quarter of use
- Remember: persistent-memory patterns and what NOT to save
- Debugging: how to investigate when the model produces wrong output
- Agent design: when to build an agent vs a skill vs a hook

Plus six to seven additional pages (full enumeration pending Confluence export).

`page-format-spec.md` captures the page format itself (header callout, "Where to Go Next" footer, parent-page navigation). The spec is portable harness content beyond just the corpus.
